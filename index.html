Google Sheets API Integration

You can connect this dashboard to a live Google Sheet. When enabled, all details you input will immediately reflect in your Google Sheet, and the dashboard will fetch its information from your sheet in real-time.

Paste the deployed Web App URL from your Google Apps Script editor.

Setup Instructions

  1. Open your Google Sheet (or create a new one).
  2. Go to Extensions -> Apps Script.
  3. Open the file google_apps_script.js in your workspace, copy its contents, and paste it into the script editor.
  4. Click the Save icon.
  5. Click Deploy -> New deployment. Select type: Web app.
  6. Set:
    • Execute as: Me (your email)
    • Who has access: Anyone (this allows the dashboard to save transactions).
  7. Click Deploy and copy the Web App URL.
  8. Paste the URL above and click "Enable Google Sheets Sync".
